# MIRA · 微创遥操作实验室

一个在浏览器本地运行的三维遥操作演示。官方 Unitree G1 双臂、胸部概念安装的官方 Z1 持镜臂、dVRK 器械 CAD，以及同源配准的 BodyParts3D 肝胆解剖共同组成可交互工作空间。

在线演示：<https://wu-make.github.io/surgical-teleop/>

## 运行

需要 Node.js 22.12+，以及支持 WebGL 2、ES modules 和 Web Workers 的现代桌面浏览器。推荐使用近期版本 Chrome 或 Edge。核心交互完全本地计算，不调用 AI API，不上传操作或个人数据。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

`dist/` 为 GitHub Pages 静态部署产物。页面和全部模型采用相对资源路径；不依赖模型 CDN、外部字体或实时后端。首次加载约 27 MB 公开模型与体积数据，需要生成肝脏表面，后续资源可由浏览器 HTTP 缓存复用。

## 操作

| 输入 | 功能 |
| --- | --- |
| 1 / 2 / 3 | 左侧持针钳、右侧弯剪、内窥镜 |
| W / S、A / D | 前后、左右移动；选中镜头时 W/S 插入退出，A/D 绕 RCM 转向 |
| Q / E | 器械下降、上升；选中镜头时俯仰 |
| 方向键 | 器械腕部俯仰、偏转，或手动镜头方向 |
| Z / X | 轴向连续多圈旋转，读数保留累计角度 |
| C / V | 闭合、张开 |
| Shift | 恒定低速精细控制；控制台也可保持精细模式 |
| Space | 按住离合，冻结位姿输入 |
| [ / ] | 任意器械选择下，内窥镜后退、前进 |
| F | 器械尖端自动居中开关 |
| B | 启用或关闭右剪几何切除 |
| Ctrl Z / Ctrl Y / Ctrl Shift Z | 撤销、重做 |
| P | 暂停、继续 |
| R | 恢复完整器官与初始器械 |
| Tab | 交换内窥镜与系统总览 |

轻点键盘从低速起步，持续按住逐渐加速，释放立即停止；平移和旋转的混合方向分别归一化。标准平移最高 35 mm/s，Shift 精细平移为 1.4 mm/s；短按实际位移还取决于按住时长，不能将此称作组织切面精度。控制台支持短点击、按住连续操作及 Enter 键激活。释放按键、取消触摸、窗口失焦会清空输入；切换到后台时暂停。系统总览可用鼠标拖动与滚轮观察。

“当前器械表面就位”使用实际组织表面，兼容切下的独立组织块。“切离与移开示范”走同一器械控制和三维体积运算，完成抓持、牵拉、切断连接、夹持移开；没有预制标本、替换模型或按时间强制分离。手动输入可立即接管；一次示范对应一个可撤销操作。

剪切：选择右剪，贴近肝脏表面，启用剪切并闭合剪口。真实刃方向上的 8 mm 刃段与组织做体积布尔运算，新鲜实质与包膜使用不同三维材质，切腔有闭合表面，主辅画面保持一致。向器官深处切割会先形成内部切腔，贯通表面后才有外部缺口；没有将“剪口闭合”直接等同于删除整片器官。按操作手势记录历史，最多保存 40 次；历史同时保存器械、抓持锚点、形变和切除记录。恢复历史后自动解除剪切，避免意外再次切除。重置丢弃未完成的旧几何结果，恢复完整器官。

左钳在实际表面附近闭合后抓持，移动会改变真正的三维顶点、解析法线与阴影。开启右剪不会释放左钳。显示、接触和切割共享同一个可逆形变映射，切割冻结当时的材料映射；松开左钳后组织平滑回弹，切痕仍留在相同材料位置。形变半径随牵拉幅度扩大以避免网格翻折，不以隐藏的牵拉距离上限截断跟手。

剪刀切断全部连接后，Worker 根据体积节点的 26 邻接连通性提取真正独立的组织组件。未切断的组织桥和对角连接仍被视为连接；源模型已有的小岛不会因首次剪切凭空脱落。切离块保留源材料、完整三维表面和新鲜切面，同时从母体几何与接触查询中去除。剪切造成的细小耗损和独立标本体积在界面中分别计量。

若左钳正夹着被切离的材料，自动转为夹持该标本：平移、抬起和腕部旋转作用于整个独立块，原肝脏回弹；V 松开后标本在简化重力、阻尼和采样接触下放落，点击“左钳接近标本”后 C 可以再次夹取，工具沿同一防碰撞控制器接近真实标本表面。标本的冻结形变、位置、旋转、抓持偏移、释放状态和切离事件均进入历史与 JSON 导出；撤销/重做不会把已经移开的材料复制回母体。重置同时恢复肝脏、移除标本并清空事件。

内窥镜可关注当前器械、双器械中心或牵拉切除协作区。球面方向平滑与连续画面上方向避免切换时猛甩或过极点翻转；跟随直接使用仿真 TCP，围绕固定入腹点转动，并保留合理观察距离及肝表面防穿透检查。标尺按当前 TCP 深度投影，仅表示仿真空间尺度。

## 外观、机构与物理边界

- G1 29 自由度、Z1、dVRK 持针钳/单极弯剪/直视内窥镜均保留所引用公开 CAD 的实际几何与尺寸。器械腕关节与开合采用源关节变换；杆轴穿过固定 RCM，工具 TCP 与控制状态一致。
- 胸部安装适配架、G1–Z1–dVRK 的组合与连接为本演示的自定义概念集成，尚无该整机的厂家 CAD、负载、标定或真机验证。它不是制造商认证的医疗配置。
- 肝脏、胆囊、肝总动脉及周边胃/十二指肠来自同一公开成人参考解剖，保持源坐标配准。周边器官作为解剖背景，只有肝脏支持体积切除。体积网格间距 **1.5 mm**，具有亚体素插值表面；表面轻度平滑减少体素台阶，器械低速操作不等于切面具有亚毫米材料精度。包膜斑理、细小纹理、湿润反光和切面颗粒属于程序显示材质，不是显微组织重建，也未编造患者特定内部血管。
- 切除是球/胶囊与有符号距离场的几何布尔运算；独立块按离散体积连通性判断，低于体素尺度的组织桥不能可靠分辨。牵拉是可逆局部几何形变，独立块采用刚体搬运与简化接触；未实现经标定的软组织有限元、出血、热损伤、血管保护、触觉力或完整临床术式。切面颗粒、细小管腔与结缔组织纹理仅为程序性显示细节。
- 按演示需求，工具无位置工作区围栏、插入锥限制或腕角限制，连续旋转也不受 URDF 角度截断。双器械使用保守胶囊包络防碰撞，不能称作整机逐三角形接触动力学。G1 本身保留源关节尺寸与姿态限制；器械超出真实手臂可达范围时使用明确的概念主从连接，不回退工具指令或拉伸 CAD。自由演示模式并不代表真机电缆、驱动器或关节能无限旋转。
- 原始项目报告、合同及提取的内部资料均只在本地 `research/`，由 `.gitignore` 排除；不进入代码仓库或网页产物。

## 实现

`src/simulation.js` 负责确定性输入、连续防碰撞、镜头跟随和复合历史；`authentic-assemblies.js` 驱动真实 CAD 关节与装配；`scene.js` 用 Three.js 在单画布上渲染两个视角；`interaction-controller.js` 统一抓持和刃段切除，`guided-demo.js` 提供同一控制路径下的可撤销示范；`tissue-worker.js` 在 Worker 中局部更新 SDF、封闭三角网格及拓扑组件，`tissue.js` 管理形变、查询、队列与版本，`tissue-fragments.js` 负责独立标本、姿态、夹持及释放接触，`tissue-material.js` 提供三维包膜与实质显示。

测试覆盖时间步一致性、连续多圈、独立器械、双器械防碰撞及接触后离开、暂停/离合、镜头过极点与协作跟随、复合状态历史、实际顶点牵拉、真实切腔闭合性、形变后切除与释放一致性、查询优化精度、晚到任务失效与重置。测试通过表示这些已列条件下的验证结果，不代表任意设备和输入序列下零缺陷。
