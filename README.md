# MIRA · 微创遥操作实验室

一个在浏览器本地运行的三维遥操作演示。官方 Unitree G1 双臂、胸部概念安装的官方 Z1 持镜臂、dVRK 器械 CAD，以及 BodyParts3D 解剖肝脏共同组成可交互工作空间。

在线演示：<https://wu-make.github.io/surgical-teleop/>

## 运行

需要 Node.js 22.12+，以及支持 WebGL 2、ES modules 和 Web Workers 的现代桌面浏览器。推荐使用近期版本 Chrome 或 Edge。核心交互完全本地计算，不调用 AI API，不上传操作或个人数据。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

`dist/` 为 GitHub Pages 静态部署产物。页面和全部模型采用相对资源路径；不依赖模型 CDN、外部字体或实时后端。首次加载约 27 MB 公开模型与体积数据，需要生成肝脏表面，后续资源可由浏览器 HTTP 缓存复用。

## 操作

| 输入 | 功能 |
| --- | --- |
| 1 / 2 / 3 | 左侧持针钳、右侧弯剪、内窥镜 |
| W / S、A / D | 前后、左右移动；选中镜头时 W/S 插入退出，A/D 绕 RCM 转向 |
| Q / E | 器械下降、上升；选中镜头时俯仰 |
| 方向键 | 器械腕部俯仰、偏转，或手动镜头方向 |
| Z / X | 轴向旋转 |
| C / V | 闭合、张开 |
| Shift | 按住临时降低操作速度；控制台也可保持精细模式 |
| Space | 按住离合，冻结位姿输入 |
| [ / ] | 任意器械选择下，内窥镜后退、前进 |
| F | 器械尖端自动居中开关 |
| B | 启用或关闭右剪几何切除 |
| Ctrl Z / Ctrl Y / Ctrl Shift Z | 撤销、重做 |
| P | 暂停、继续 |
| R | 恢复完整器官与初始器械 |
| Tab | 交换内窥镜与系统总览 |

控制台按钮支持按住连续操作。释放按键、取消触摸、窗口失焦会清空输入；切换到后台时暂停。系统总览可用鼠标拖动与滚轮观察。

剪切：选择右剪，向肝脏表面移动，启用剪切并闭合剪口。刀尖接触区域从真实三维体积中扣除，切腔有闭合表面，主辅画面保持一致。按操作手势记录历史，最多保存 40 次；恢复历史后自动解除剪切，避免意外再次切除。重置丢弃未完成的旧几何结果，恢复完整器官。

左钳闭合接触组织时可以产生局部牵拉显示形变；开启剪切会释放该形变，防止显示坐标与切除坐标不一致。内窥镜跟随使用场景中实际工具 TCP，围绕固定入腹点转动，并限制与器械的工作距离；镜头进深还有肝脏表面距离检查。标尺按当前 TCP 深度投影，仅表示仿真空间尺度。

## 外观、机构与物理边界

- G1 29 自由度、Z1、dVRK 持针钳/单极弯剪/直视内窥镜均保留所引用公开 CAD 的实际几何与尺寸。器械腕关节与开合采用源关节变换；杆轴穿过固定 RCM，工具 TCP 与控制状态一致。
- 胸部安装适配架、G1–Z1–dVRK 的组合与连接为本演示的自定义概念集成，尚无该整机的厂家 CAD、负载、标定或真机验证。它不是制造商认证的医疗配置。
- 肝脏来自公开成人参考解剖。体积网格间距 **1.5 mm**，具有亚体素插值表面；表面轻度平滑减少体素台阶，器械低速操作不等于切面具有亚毫米材料精度。
- 切除是球/胶囊与有符号距离场的几何布尔运算。牵拉是受限的局部显示形变；未实现经标定的软组织有限元、出血、热损伤、血管保护、触觉力或完整临床术式。
- RCM、工作空间和关节限位属于运动学约束，不构成全身碰撞动力学或真机控制。自动持镜直接读取仿真位姿，不假称运行视觉模型或自主手术算法。
- 原始项目报告、合同及提取的内部资料均只在本地 `research/`，由 `.gitignore` 排除；不进入代码仓库或网页产物。

## 实现

`src/simulation.js` 负责确定性输入、运动学状态、镜头跟随和有界复合历史；`authentic-assemblies.js` 驱动真实 CAD 关节与 RCM 装配；`scene.js` 用 Three.js 在单画布上渲染两个视角；`tissue-worker.js` 在 Worker 中局部更新 SDF 和封闭三角网格，`tissue.js` 管理队列、版本与 GPU 资源回收。

测试覆盖时间步一致性、独立器械、限位、暂停/离合、自动居中、镜头进退、复合状态历史、真实切腔闭合性、几何索引、晚到任务失效与重置。测试通过表示这些已列条件下的验证结果，不代表任意设备和输入序列下零缺陷。
