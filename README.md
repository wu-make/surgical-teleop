## 第一次使用

1. **[打开演示](https://wu-make.github.io/surgical-teleop/)**，等待模型加载完成。推荐用电脑上的 Chrome 或 Edge，无需安装项目。
2. 点击画面下方的 **「切离与移开示范」**，先看一遍夹住组织、牵拉、切断连接和移开的过程。过程中也可以用键盘接管。
3. 按 **R** 恢复起始状态，再自己试。完整按键随时可以在网页右上角 **「操作指南」** 查看，控制台按钮也能直接操作。

首次会加载约 27 MB 的模型与组织数据。看到加载提示时稍等即可；不需要先配置 Node.js 或启动本地服务。

## 自己操作一次

**左钳夹住 → 牵拉 → 右剪切断连接 → 左钳移开 → 松钳放下。**

| 想做什么 | 怎么操作 |
| --- | --- |
| 夹住一小块组织 | 按 **1** 选左钳 → 点击「当前器械表面就位」→ 按 **C** 闭合 |
| 抬起、牵拉 | 保持左钳夹持，用 **WASD / Q、E** 移动；按住 **Shift** 更慢、更细 |
| 剪切组织 | 按 **2** 选右剪，靠近被牵起组织的连接处，按 **C** 闭合；配合移动继续剪切 |
| 搬走切下的组织 | 连接全部切断后，左钳可带着独立组织块移动、抬起和旋转 |
| 松开、重新夹取 | **V** 松钳；需要重抓时，点击「左钳接近标本」，再按 **C** |
| 尝试局部止血 | 点击「右端接近渗血切面」，等器械就位后按住 **H**，观察局部渗血变化 |

![左钳夹持已经切离的独立组织块，可继续抬起、移动或旋转](docs/images/held-specimen.jpg)

*切离后的组织块由左钳夹持；按 V 松开后会落下，仍可重新夹取。*

- **剪口闭合了，组织还连着？** 剪口要实际接触组织，且必须剪断全部连接，组织块才会分离。
- **左钳夹不到？** 先按 V 张开，贴近组织表面，再按 C。空钳闭合后移动不会自动吸住组织。
- **松钳后发生什么？** 未切离的组织会滑脱回弹；已经切离的组织块会放落。
- **找不到器械或标本？** 先开启「自动持镜」，也可在「观察内容」中切换到「独立标本」。按 R 可整体重来。

## 常用按键

有键盘操作经验的话，记住 **1 / 2 切换、WASD 移动、C / V 开合、Shift 精细、R 重来** 就能先玩起来。

| 按键 | 功能 |
| --- | --- |
| **1 / 2 / 3** | 选择左钳 / 右剪 / 内窥镜 |
| **WASD** · **Q / E** | 前后左右移动 · 下降 / 上升 |
| **C / V** | 闭合 / 张开；右剪默认可以剪切，不用另外开启 |
| **Shift** | 按住进行精细、低速操作 |
| **方向键** · **Z / X** | 调整腕部方向 · 轴向连续旋转 |
| **F** · **[ / ]** | 开关自动持镜 · 镜头后退 / 前进 |
| **H**（按住） | 器械接触渗血切面时进行局部压迫 |
| **Ctrl Z / Ctrl Y** · **R** | 撤销 / 重做 · 重置器官、双臂和镜头 |
| **P** · **Tab** | 暂停 / 继续 · 交换内窥镜与系统总览 |

**鼠标看视角：** 关闭自动持镜后，在内窥镜画面上拖动可转向；滚轮缩放视野。系统总览也支持拖动和滚轮观察。

## 这个项目能做什么

- **双视角观察：** 内窥镜看局部操作，系统总览看机器人与器械装配。
- **组织交互：** 局部夹取和牵拉、剪切后形成缺损、独立组织块搬运与松钳放落。
- **出血与压迫：** 血液沿组织表面流动，附着血液随标本移动，可尝试接触式局部压迫。
- **随时重来：** 撤销、重做、完整重置，也可从网页导出操作与性能记录。

场景使用 Unitree G1 / Z1、dVRK 器械和 BodyParts3D 解剖资产。胸部持镜与整机装配属于概念集成；组织、血流和止血是简化交互模型，**不是经临床验证的训练系统，也不控制真实机器人**。帧率受设备、窗口和浏览器调度影响，连续剪切仍可能卡顿，尚不保证稳定 60 FPS。

## 本地运行

只想体验，直接使用上方的在线演示即可。需要改代码时，再在本地运行：

```sh
git clone https://github.com/wu-make/surgical-teleop.git
cd surgical-teleop
npm ci
npm run dev
```

需要 **Node.js 22.12+**。浏览器打开终端显示的地址，默认是 `http://127.0.0.1:4173/`；关闭本地服务后，这个地址就无法继续访问，在线演示不受影响。

```sh
npm test          # 运行测试
npm run build    # 生成 dist/ 静态网站
npm run preview  # 本地预览构建结果
```

开发者可继续阅读 [技术说明与历次测试记录](docs/DEVELOPMENT-NOTES.md)。
