# MIRA · 微创遥操作实验室

一个在浏览器本地运行的三维遥操作演示。官方 Unitree G1 双臂、胸部概念安装的官方 Z1 持镜臂、dVRK 器械 CAD，以及同源配准的 BodyParts3D 肝胆解剖共同组成可交互工作空间。

在线演示：<https://wu-make.github.io/surgical-teleop/>

## 运行

需要 Node.js 22.12+，以及支持 WebGL 2、ES modules 和 Web Workers 的现代桌面浏览器。推荐使用近期版本 Chrome 或 Edge。核心交互完全本地计算，不调用 AI API，不上传操作或个人数据。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

`dist/` 为 GitHub Pages 静态部署产物。页面和全部模型采用相对资源路径；不依赖模型 CDN、外部字体或实时后端。首次加载约 27 MB 公开模型与体积数据，需要生成肝脏表面，后续资源可由浏览器 HTTP 缓存复用。

## 操作

| 输入 | 功能 |
| --- | --- |
| 1 / 2 / 3 | 左侧持针钳、右侧弯剪、内窥镜 |
| W / S、A / D | 前后、左右移动；选中镜头时 W/S 插入退出，A/D 绕 RCM 转向 |
| Q / E | 器械下降、上升；选中镜头时俯仰 |
| 方向键 | 器械腕部俯仰、偏转，或手动镜头方向 |
| Z / X | 轴向连续多圈旋转，读数保留累计角度 |
| C / V | 闭合、张开 |
| Shift | 恒定低速精细控制；控制台也可保持精细模式 |
| Space | 按住离合，冻结位姿输入 |
| [ / ] | 任意器械选择下，内窥镜后退、前进 |
| F | 器械尖端自动居中开关 |
| B | 启用或关闭右剪几何切除 |
| H（按住） | 当前器械稳定接触切面的局部压迫；开始时自动关闭剪切 |
| Ctrl Z / Ctrl Y / Ctrl Shift Z | 撤销、重做 |
| P | 暂停、继续 |
| R | 恢复完整器官、双臂实际关节、器械与镜头，双尖端同时入镜 |
| Tab | 交换内窥镜与系统总览 |

轻点键盘从低速起步，持续按住逐渐加速，释放立即停止；平移和旋转的混合方向分别归一化。标准平移最高 35 mm/s，Shift 精细平移为 1.4 mm/s；短按实际位移还取决于按住时长，不能将此称作组织切面精度。控制台支持短点击、按住连续操作及 Enter 键激活。释放按键、取消触摸、窗口失焦会清空输入；切换到后台时暂停。系统总览可用鼠标拖动与滚轮观察。

“当前器械表面就位”使用实际组织表面，兼容切下的独立组织块。“切离与移开示范”走同一器械控制和三维体积运算，完成抓持、牵拉、切断连接、夹持移开；没有预制标本、替换模型或按时间强制分离。手动输入可立即接管；一次示范对应一个可撤销操作。

剪切：选择右剪，贴近肝脏表面，启用剪切并闭合剪口。从真实弯剪 CAD 对向钳口边界提取的完整曲线刃段与组织做体积布尔运算；检测覆盖每段的中部，切割使用同一条刃线和 2.4 mm 几何半径，新鲜实质与包膜使用不同三维材质，切腔有闭合表面，主辅画面保持一致。向器官深处切割会先形成内部切腔，贯通表面后才有外部缺口；没有将“剪口闭合”直接等同于删除整片器官。按操作手势记录历史，最多保存 40 次；历史同时保存器械、抓持锚点、形变和切除记录。恢复历史后自动解除剪切，避免意外再次切除。重置先使正在执行的交互和旧几何结果失效，再恢复完整器官、机器人实际关节、器械初始位置、腕角、开合及内窥镜，清除抓持和历史。起始取景按当前画面宽高计算两实际 TCP 的投影余量，首次显示即同时看见双尖端。

左钳在实际表面附近闭合后抓持，移动会改变真正的三维顶点、解析法线与阴影。开启右剪不会释放左钳。显示、接触和切割共享同一个可逆形变映射，切割冻结当时的材料映射；松开左钳后组织平滑回弹，切痕仍留在相同材料位置。夹持核心半径约 2.5 mm，周边影响半径固定为 18 mm；连续可逆小步映射让局部材料跟随钳尖并形成小范围张力，远处肝体保持锚定，不再随抬升把整个器官纳入变形。未切离组织在过度牵拉时会出现明确的夹持滑脱，器械仍可自由移动；张开再闭合后可重新夹取。该阈值是演示模型的材料应变策略，不是经测量的手术安全力值。旧快照的单步映射保留还原兼容。

剪刀切断全部连接后，Worker 根据体积节点的 26 邻接连通性提取真正独立的组织组件。未切断的组织桥和对角连接仍被视为连接；源模型已有的小岛不会因首次剪切凭空脱落。切离块保留源材料、完整三维表面和新鲜切面，同时从母体几何与接触查询中去除。剪切造成的细小耗损和独立标本体积在界面中分别计量。

若左钳正夹着被切离的材料，自动转为夹持该标本：平移、抬起和腕部旋转作用于整个独立块，原肝脏回弹；V 松开后标本在简化重力、阻尼和采样接触下放落，点击“左钳接近标本”后 C 可以再次夹取，工具沿同一防碰撞控制器接近真实标本表面。标本的冻结形变、位置、旋转、抓持偏移、释放状态和切离事件均进入历史与 JSON 导出；撤销/重做不会把已经移开的材料复制回母体。重置同时恢复肝脏、移除标本并清空事件。

初始和重置时，内窥镜先显示双器械尖端；首次器械操作后切换为以正在操作的器械实际 TCP 为唯一中心目标。显式选择双器械中心或牵拉协作区会保留该选择。当前器械模式下，不将肝脏表面锚点混入光轴；工具正常连续移动时逐帧居中，较大的器械切换仍限速转向。也可明确选择双器械中心或牵拉切除协作区；这两种双器械取景会按实际光轴、滚转、画面比例与当前 FOV 自动退镜，为双尖端保留余量。镜头退到可用位置仍不足时提示用滚轮缩小画面。协作模式下，切离后选左钳搬运会转为跟随左钳，启用剪切开关不会把镜头一直留在两器械中间。球面方向与连续画面上方向避免过极点翻转；镜头围绕固定入腹点转动，自动进退维持约 65 mm 观察距离，保留肝表面防穿透。关闭自动持镜后，在主内窥画布上按住鼠标左键拖拽可转向；滚轮光学变焦范围为 25–80°，两种模式均可用。光学变焦改变 FOV 而不偷偷移动实体镜头；W/S 或 [ / ] 才是实际进退。视角复位恢复默认 FOV 和方向；单次拖拽/滚轮手势可撤销，暂停、离合和失焦会停止手势。独立标本观察按真实包围球调整取景距离，中心仍尊重明确选择的跟随目标。标尺按当前 TCP 深度和实际 FOV 投影，仅表示仿真空间尺度。

连续扫切按实际 CAD 刃段记录路径，平移、旋转弧和牵拉中的材料移动均以不超过 1 mm 的间隔补采样；Worker 忙碌时保留路径，逐批完成，每批最多 64 条真实刃段。每个采样冻结当时的组织形变，并逐姿态判断切离，后续刀路不会重复切除已独立的标本。关闭剪切、张开剪口、离合或暂停会断开后续路径；先前已经执行的合法剪切仍会完成，暂停时等待继续。处理期间提示更新组织，暂缓撤销、导出和新的自动操作，历史合并到最近的完整状态；重置直接使旧队列失效。缓冲达到上限会明确停止接收并提示重新启用，不静默丢弃路径或强制拉断组织桥。

左钳每次张开再闭合只尝试一次夹取，使用 2 mm 的显示表面接触容差；空钳闭合后移动不会自动吸住组织，未夹到或滑脱时需先 V 张开，再贴近后 C 夹取。该容差服务于 1.5 mm 采样网格，并非临床接触精度。切离后的抓持转换按原材料点是否位于该组件体积内判断，不能用“离标本很近”替代所属关系，以免相邻母体被错误关联到独立标本。

渗血只由真实体积切除产生的新鲜切面触发，不由 B 开关或播放时间触发。实际切面和周边包膜上的材料单元存储血量，按重力势与液层高度交换体积，牵拉时按表面面积变化调整液层厚度；离开支撑面的血滴受重力并与母体表面接触。血滴接触复用当前可见切后网格的三角形层级，检查首个向内穿越与末端球形重叠，避免逐血滴重算全部历史切割映射；这仍是小液体包的接触近似，并非完整连续流体求解。静止组织的材料点姿态复用，形变或标本搬运时更新，切面邻域先按包围范围筛选，血膜连接使用局部空间索引。血液使用有厚度的三维几何，达到血滴预算时合并邻近液体包，不把血量藏入不可见计数。切离块停止母体灌注，已有表面血液随标本搬运。切面另有固定在材料坐标上的细小纤维几何与分尺度实质材质，属于显示细节，不是患者血管或显微组织重建。

按住 H 使用当前闭合器械稳定接触切面进行局部压迫近似，并自动关闭剪切。只有接触区域降低新流入，持续接触可积累局部凝血状态；移开后可再渗血，已有血液不会被删除。这不是压力传感、能量凝血、缝扎或临床术式模拟。界面血量是该未标定模型的体积记录，不是患者失血预测。血量、血膜、血滴与局部凝血同时进入撤销/重做和 JSON 记录，重置清空。

未切断组织松钳后保持材料连接，以连续位姿和阻尼回落滑出钳口，不生成刚体标本；已切离组织松钳后解除刚体夹持，在按速度细分的重力步进和接触下放落。轻微采样法线误差不会在平缓支撑面凭空制造侧向弹射。

## 外观、机构与物理边界

- G1 29 自由度、Z1、dVRK 持针钳/单极弯剪/直视内窥镜均保留所引用公开 CAD 的实际几何与尺寸。器械腕关节与开合采用源关节变换；杆轴穿过固定 RCM，工具 TCP 与控制状态一致。
- G1 源 CAD 的橡胶手型为固定几何，不含可驱动手指。定制掌托、两条实体绑带、短球接轴夹将原始手框架与真实器械近端杆轴连接；全部保留源几何尺寸。完整切离示范已验证双掌持续连接，超出实际可达范围仍按概念主从状态显示。
- 胸部安装适配架、G1–Z1–dVRK 的组合与连接为本演示的自定义概念集成，尚无该整机的厂家 CAD、负载、标定或真机验证。它不是制造商认证的医疗配置。
- 肝脏、胆囊、肝总动脉及周边胃/十二指肠来自同一公开成人参考解剖，保持源坐标配准。周边器官作为解剖背景，只有肝脏支持体积切除。体积网格间距 **1.5 mm**，具有亚体素插值表面；表面轻度平滑减少体素台阶，器械低速操作不等于切面具有亚毫米材料精度。包膜使用低饱和棕紫色、平滑湿润反光，切面使用区别于包膜的红褐颗粒、纤维间隔及细小凹口；这些光学特征属于程序显示材质，不是显微组织重建，也未编造患者特定内部血管。
- 切除是球/胶囊与有符号距离场的几何布尔运算；独立块按离散体积连通性判断，低于体素尺度的组织桥不能可靠分辨。牵拉是可逆局部几何形变，独立块采用刚体搬运与简化接触；血膜和血滴按简化体积守恒、重力和接触计算；压迫与凝血参数未标定，不代表临床止血效果。未实现经标定的软组织有限元、热损伤、患者特定血管保护、触觉力或完整临床术式。切面颗粒、细小管腔与结缔组织纹理仅为程序性显示细节。
- 按演示需求，工具无位置工作区围栏、插入锥限制或腕角限制，连续旋转也不受 URDF 角度截断；平移、腕部旋转和开合仅在接近另一器械实体时阻止继续靠近，反向或沿接触面移动可以离开。碰撞包络从源 CAD 的全部三角形分段拟合，分别覆盖真实杆身、腕部和两片钳口，随实际关节变换；不再用 TCP 大球填满钳口周围的空隙。包络含 0.15 mm 安全余量，分段曲率仍有保守拟合误差，不能称作整机逐三角形接触动力学。提示区分体内/体外杆身、腕部、钳口/剪口，在最近位置显示小型接触标记；释放输入或离开后立即清除阻挡提示。G1 本身保留源关节尺寸与姿态限制；器械超出真实手臂可达范围时使用明确的概念主从连接，不回退工具指令或拉伸 CAD。自由演示模式并不代表真机电缆、驱动器或关节能无限旋转。
- 原始项目报告、合同及提取的内部资料均只在本地 `research/`，由 `.gitignore` 排除；不进入代码仓库或网页产物。

暂停后可点击“单步 0.05 s”逐步观察牵拉、滑脱、独立块落下和血流；每次推进同一套控制、CAD 接触和组织 Worker，完成后保持暂停。血膜凝固会降低局部流动性，但模型未做生理参数标定。

## 流畅度与细节保留

组织仍使用相同的 1.5 mm 采样体积、完整切后三角网格、材料坐标材质、血膜单元与三维血滴。优化不降低画布像素比、切面精度、血滴预算或物理子步。支持 WEBGL_multi_draw 时，器官分块、独立标本和相同材质的静态手术室几何通过合批提交；所有位置、法线、颜色、材料坐标、切面标记和三角索引保留，原始网格继续负责接触与历史。不支持该扩展时继续使用原网格渲染。

Worker 缓存切面材料采样，完成出血单元选择与邻接图计算；主线程接收相同的选择结果并保持血量、凝血和夹持状态。血滴采用保守空间分块筛选，再查询完整三角形层级。显示帧时间诊断按切割、压迫及其他操作分组，记录未经过仿真时间截断的真实渲染间隔与 P95/P99，支持定位慢帧；硬件、窗口大小和浏览器前后台状态仍影响帧率。

### 长时测试记录

2026-10-17 在公开部署页、浏览器前台实测，同一套控制器连续栅格切割并持续出血。7200 个连续切割帧覆盖 120.0456 秒，平均 59.977 FPS，P95 18.3 ms、P99 24.3 ms；13 帧超过 33.34 ms，0 帧超过 50 ms。此结果来自当次侧栏窗口（内窥渲染 355 × 504），不能外推为任意分辨率或设备都稳定 60 FPS。测试保留完整几何、原有材质、血液预算和计算时间步。

继续操作后实际切离约 1.54 cm³ 标本，左钳夹持移开，松钳后同一标本下落并停在接触面。右剪闭合接近实际渗血切面，按住压迫 6.074 秒，接触 3 个局部渗血单元。切离转换后的统计出现过一帧超过 50 ms，因此不能把上述连续窗口结果表述为全流程零卡顿。止血是未标定的局部压迫与凝血近似，不能表示真实临床止血效果。

会话导出（顶部“导出记录”，窄屏也可在“操作指南”中导出）保存整轮分阶段帧数、累计测量时长、慢帧计数与最长帧；最近 7200 帧另存 P50/P95/P99 和按时间顺序的原始间隔。窗口覆盖早期记录时，整轮计数仍保留。重置或开始新示范会开始新一轮统计。暂停、页面隐藏及历史恢复跨越的间隔不会计入恢复后的第一帧。

### 全屏切离转换复核（2026-10-18）

消除新网格加入批次后同帧再次复制全部属性的重复工作。Worker 预先计算完整标本冻结顶点、法线、边界、26 个原有支撑点及完整三角形接触索引；牵拉后的父体索引仍按实际显示顶点精确更新边界。血液节点复用同一次材料映射的权重和梯度，刚体搬运只更新姿态；加载期间准备血液颜色属性和双视角着色器。以上均不减少三角形、材质属性、血液容量、渲染分辨率或物理时间步。

最终构建在真实全屏状态、1921 × 1082 内窥渲染尺寸和原有 1.1 像素比下，连续切割出血 187.5686 秒，11218 个切割帧平均 59.807 FPS，最长 48.5 ms，61 帧超过 33.34 ms，0 帧超过 50 ms。其中连续 7200 帧窗口覆盖 120.2698 秒，平均 59.865 FPS，P95 24.2 ms、P99 30.3 ms。全屏状态和实际渲染尺寸变化写入导出，避免把普通窗口或全屏切换过程误计为全屏验收。

真实切离转换的前台接收处理为 4.6 ms（标本装配 0.6 ms）；转换前 100 ms 至后 500 ms 的窗口内最长显示间隔 42.4 ms，未再出现超过 50 ms 的帧。夹取和局部牵拉、实际切断、约 1.51 cm³ 独立标本搬运、键盘精细抬移和松钳重力下落均在同一控制/体积链路验证。局部压迫实际接触 2 个渗血单元并持续约 6.09 秒，凝血和局部供血抑制发生变化，已有血量保持守恒；不代表整片切面全部止血或临床有效性。

这些数值是本机这次运行的测量。全屏切换及操作开始仍存在瞬时慢帧（本次压迫阶段有一帧 72.8 ms）；它们在整轮会话计数和导出中保留，不能据此宣称全流程零卡顿或任意设备稳定 60 FPS。217 项自动测试通过，包含工作线程传输前后的全部几何属性、材料边界/支撑点、接触查询与变形重定位、血流映射精确一致性、血量守恒和历史恢复。

### 剪口闭合、压迫起始与窗口验收（2026-10-18）

右剪现在记录张开至闭合期间的完整真实 CAD 剪刃扫掠，而不是等钳口小于 22% 才开始记录。张开和停在张开位置不会剪切；关闭 B 或压迫时也不会产生新剪切。术野内新增可点击的 B 开关、剪刃状态、实际切削体积和独立标本数，全屏时也能看到；提示显示在当前全屏元素内。接触容差与实际切削半径一致，组织块仍须所有连接贯通后才独立，不会因右剪闭合就删除整块组织。

压迫及操作检查点保留完整血液、标本、夹持和位姿状态，共享不可变的切割记录，省去整段历史的重复验证和复制。热接触查询使用独立普通数值数组，避免冻结数组的访问回退；切口空间索引以保守包围盒跳过不可能改变结果的切口，增量边界及正负距离均与完整线性 CSG 做逐值比较。HDR 存储在加载时准备，并以精确活动像素与 UV 区域复用；画布只跳过相同尺寸通知。未减少几何、切面材质、血膜/血滴容量、成像分辨率和物理时间步。

按用户后续要求，最终长时测试在右侧普通窗口进行，内窥渲染 949 × 612、原像素比 1.1。引导流程通过同一控制器完成夹取、局部牵拉和真实栅格切断，随后实际键盘抬移、松钳、重新接近并夹取、接近切面及压迫。12741 个连续切割帧覆盖 214.4369 秒，平均 59.416 FPS，最长 48.5 ms，84 帧超过 33.34 ms，0 帧超过 50 ms。真实提取约 1.510 cm³ 标本，手动精细搬运保持同一材料身份，松钳后下落约 85 mm 并停稳，随后成功重新夹取。切离转换仍有一帧 54.6 ms，归入操作阶段而非连续切割阶段，因此不能称全流程零卡顿。

实际 H 压迫接触 3 个渗血单元，累计接触约 6.024 秒；361 个压迫帧覆盖 6.0123 秒，平均 60.044 FPS、最长 36.4 ms，无超过 50 ms 的压迫帧。起始事件处理 2.8 ms；撤销恢复压迫前血流状态，重做恢复接触累计，切削数和独立标本均保持一致。已有血液和未压迫部位的供血继续计算，不代表整片切面或临床止血。

逐项验证六向移动、四向腕部、轴转、开合、镜头进退、连续超过一圈旋转、鼠标转向与滚轮变焦、跟随模式、标本观察、暂停/单步/继续、主辅视图、导出、说明弹窗和重置。总览拖拽仍绑定画布，避免捕获按钮点击。重置恢复完整器官、零血液、零标本及双臂初始位姿，双尖端入镜。223 项自动测试通过；最后的视图事件绑定修复另通过 17 项视图相关检查及鼠标点击复核。

全屏定位阶段仍观察到浏览器原生切换的瞬时停顿；用户要求停止全屏后未再做最终全屏验收，不能声称最终版本已消除该停顿或任意设备稳定 60 FPS。另增加显卡上下文中断时暂停及恢复后重建完整材质的处理，保留组织状态；不将驱动恢复行为视为跨设备保证。

## 实现

`src/simulation.js` 负责确定性输入、连续防碰撞、镜头跟随和复合历史；`authentic-assemblies.js` 驱动真实 CAD 关节与装配；`scene.js` 用 Three.js 在单画布上渲染两个视角；`scope-context.js` 隔离母体/标本查询，`scope-framing.js` 处理取景与进退，`scope-navigation.js` 管理仅作用于主画布的鼠标转向、光学变焦与手势历史，`scope-feed.js` 将一次线性内窥渲染供给术野和室内实体监视器，统一进行一次 ACES 与 sRGB 输出转换；`operating-room.js` 构建手术床、手术灯、器械车及封闭式储物柜；`interaction-controller.js` 统一抓持和刃段切除，`guided-demo.js` 提供同一控制路径下的可撤销示范；`tissue-worker.js` 在 Worker 中局部更新 SDF、封闭三角网格及拓扑组件，`tissue.js` 管理形变、查询、队列与版本，`tissue-fragments.js` 负责独立标本、姿态、夹持及释放接触，`tissue-material.js` 提供三维包膜与实质显示。

`instrument-pose.js` 统一源 URDF 正运动学和 RCM 位姿，供 CAD 显示和碰撞共同使用；`instrument-contact.js` 检查完整杆轴及运动中的腕部/钳口，`collision-feedback.js` 生成与当前接触位置一致的即时提示。`scripts/prepare-instrument-collision.mjs` 从固定版本的 dVRK GLB 三角形生成分段包络；源文件校验值、连续三角形覆盖率和独立 GLB 变换校验进入测试。

测试覆盖时间步一致性、连续多圈、独立器械、完整源器械包络、弯腕与开合防碰撞、精确相切后反向/切向离开、截图姿态的误报回归、暂停/离合、镜头过极点与协作跟随、复合状态历史、实际顶点牵拉、真实切腔闭合性、形变后切除与释放一致性、查询优化精度、晚到任务失效与重置。测试通过表示这些已列条件下的验证结果，不代表任意设备和输入序列下零缺陷。
