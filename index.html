关闭自动持镜后，鼠标拖拽转向
滚轮光学变焦；[ / ] 镜头进退
初始与重置时双尖端入镜；操作后跟随当前尖端
左钳：选 1 → 表面就位 → C 夹住 → E 抬起，V 释放，未切离组织连续滑落回弹。右剪：选 2 → 表面就位 → C 闭合并沿表面移动。左钳夹住局部组织，邻近组织随动，远处肝体保持锚定。过度牵拉可能滑脱，张开再闭合可重新夹取。必须切断全部连接，组织块才会独立；左钳夹持时可 WASD / Q E 移开、方向键与 Z X 旋转，V 松手后独立块受重力落下；点击“左钳接近标本”，再 C 可重新夹取。未完全切断时仍是附着组织。切面与两侧缺损来自同一三维体积运算。
导出记录包含当前组织和血流状态，以及本轮操作的平均帧率、最长帧、慢帧计数和最近帧时间。暂停、后台及恢复场景的等待不计入性能统计。
